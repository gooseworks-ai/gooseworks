Start new videos from a real reference ad by default: the goose-video entry skill now picks the product, finds ads like the brand's (or takes the customer's own), and remakes the pick as a custom video. Ready-made styles stay available when nothing fits or the customer asks for one. The make-custom-video entry (3.8.0) follows the same order: without a reference it finds ads like the brand's and uses the customer's pick, never a template's demo. Release with the matching server support for finding reference ads.
